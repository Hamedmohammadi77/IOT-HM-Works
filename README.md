## 🚀 How to Run

1. Open the `.ino` file for the exercise you want in Arduino IDE.
2. Select the correct board and COM port under **Tools**.
3. Upload the sketch to your board.
4. Open the Serial Monitor (baud rate: `115200`) to view output.
